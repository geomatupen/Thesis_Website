# External 3D Splat Assets

The RAD scene folders used by the 3D viewer are intentionally not stored in this website folder.

Current local package location:

```text
D:\bimba3d-re\outputs\splats_test
```

The 3D viewer loads the public RAD scene folders from:

```text
https://raw.githubusercontent.com/geomatupen/Bimba3d-re_research_outputs/main/splats_test
```

Each scene folder must keep its full converted Spark RAD structure:

- `*-lod.rad`
- `*-lod-*.radc`
- `manifest.json`
